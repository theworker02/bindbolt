# bindbolt

Bind numeric bolt values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/bindbolt/

## Install / run

```bash
git clone https://github.com/theworker02/bindbolt.git
cd bindbolt
node src/cli.js
node --test
```
